Panel de Auditoría

Sistema de auditoría para revisión y control de calidad de datos cargados. Los auditores pueden agregar observaciones sin modificar los datos originales.

Cómo funciona el sistema de auditoría
  • Ver datos agrupados: Revise los registros por dependencia, actuario, estado, etc.
  • Agregar observaciones: Registre observaciones generales o sobre campos específicos.
  • Sin modificar datos: Las observaciones no afectan los datos reales, solo se registran aparte.
  • Resolver observaciones: Marque observaciones como resueltas cuando se corrijan.
